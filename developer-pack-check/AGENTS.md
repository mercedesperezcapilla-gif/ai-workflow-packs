# Shared rules

Read docs/ first. The implementer may change only src/lifecycle.ts and docs/handoff.md. Keep fixtures and existing tests unchanged. Run npm test and report actual exit status and findings honestly. Review against docs/acceptance.md. At most two implementation and review cycles; then stop for a person. No commits, publishing or pilot enablement.

The reviewer never edits files. Return findings in chat; the implementer records them in docs/handoff.md. Use fictional data only.

For this lesson setup, the learner may also create the named skill and reviewer under .claude/. This does not allow changing tests, fixtures or other source files.
