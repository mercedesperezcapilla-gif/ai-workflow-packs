# Check your work

All examples are fictional. Open this folder after completing the readiness check, brief, stories and evaluation set from `product-ba-pack.zip`.

`answer-key.md` gives a reference verdict, gap analysis, overlap decisions, brief, stories, risks and evaluation table. Equivalent wording is acceptable when it preserves the source decisions and test coverage. Public reference answers are a learning aid, not a blind evaluation.

Keep this folder outside the starter working folder. Nothing here creates an issue, schedules a job or sends a result.

## Reference skill and reviewer
